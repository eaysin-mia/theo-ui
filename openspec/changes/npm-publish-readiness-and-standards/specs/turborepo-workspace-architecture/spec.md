# Spec Delta: turborepo-workspace-architecture

## MODIFIED Requirements

### Requirement: Automated Package Release Pipeline

The repository SHALL maintain an automated GitHub Actions release workflow (`.github/workflows/release.yml`) triggered on pushes to `main` that integrates with Changesets to automate package versioning PRs and publication of `@theo/ui` to the public npm registry with cryptographic provenance attestation.

#### Scenario: Publishing new package version via Changesets
- **WHEN** a version bump PR generated by Changesets is merged into `main`
- **THEN** the release workflow builds, verifies, and publishes `@theo/ui` to the public npm registry using `NPM_TOKEN` with npm provenance enabled (`id-token: write`)
